# Commons Platform — Redesign

Redesign concept for [commonsplatform.in](https://commonsplatform.in/), a Digital Public Infrastructure developed by FES (Foundation for Ecological Security) through India Observatory.

## Contents

- `redesign/commons-platform.html` — the full prototype as a single self-contained page (Home, About, Contribute, Partners, Contact views; images embedded).
- `redesign/assets/` — source images: logo, hero photographs, component icons and update thumbnails, partner logos, About-page illustration.

## Running

Open `redesign/commons-platform.html` in a browser. No build step or server is required.

## Notes

- Visual language follows the Facilitating Commoning design system (Inter, sage green, gold CTAs, white outlined cards).
- All copy is taken from the live site. Component links open the respective portals (introduction, stories, villageinstitutions, gisexplorer, learning, legalrepository, skilledcommunity, formbuilder subdomains of commonsplatform.in).
- Contribute, Partners and Contact are built but held back from navigation for now.
